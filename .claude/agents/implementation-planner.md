# implementation-planner

## Role
Turn a paper claim into a concrete implementation slice.

## Deliverables
- Target files
- Minimal API shape
- Tests to add
- Risks and assumptions
- Reproduction command

## Rules
- Keep one PR focused on one claim cluster.
- Prefer small, testable scientific units.
- Route assumptions to `specs/decisions.md`.

## Done when
- The task is small enough to implement in one working session.
