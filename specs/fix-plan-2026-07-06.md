#### Task 3: nylon 縮合反応のイベント計数設計 (A5)

**目的**: 1 縮合反応(アミド結合 1 本 + 水 1 分子)が `confirmed_formation` 2 件として

独立に confirmed_formation を発行しうる。物理的には水の O–H 形成として正しい挙動
なので、**バイアス自体は維持し、計数だけを主反応(amine_N–carboxyl_C)に限定する**。

**変更内容(推奨案)**:
1. `PairSpec` に `count_as_reaction: bool = True` を追加し、

   `bonds.jsonl` に記録する(スキーマ追加は後方互換: 欠落時 True 扱い)。
3. `BondTracker.confirmed_formations()` はそのまま(全イベント)とし、
   計数側 — `analysis/conversion.py::conversion` / `conversion_timeseries`、
   `carothers.py::dpn_from_bonds` の呼び出し規約 — で
   `counts_as_reaction=True` のみをフィルタする。
   フィルタはイベント読み込み直後(`reproduce_figures.py` / `run_nylon66.py`)で行い、

### Phase 3: アルゴリズム忠実性(FIRE)

#### Task 6: FIRE を正準アルゴリズムに整列 (I1, I2, I3)

**箇所**: `src/kagome/integrators/minimize.py:93-124`

**変更内容**:
1. 速度混合をキック**前**の速度に適用する正準順序(Bitzek et al., PRL 97,
   170201 (2006) / ASE `ase.optimize.fire`)へ変更:
   ```
   power = F·v
   if power > 0:
       v = (1-α)·v + α·F̂·|v|      # 混合(キック前の v と |v|)
       n_positive += 1
       if n_positive > n_min: dt↑, α↓
   else:
       v = 0; dt↓; α=α_start; n_positive=0
   v += dt·F                        # キックは混合の後
   ```
2. N_min のオフバイワン (I2): ASE と同じ「判定してからカウント」順
   (`if n_positive > n_min: ... ; n_positive += 1` 相当)に合わせるか、
   現行維持を選ぶ。**どちらでも収束品質への影響は 1 ステップ差だが、
